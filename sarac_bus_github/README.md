# Sarač Bus

Flask web stranica za Sarač Bus.

## Pokretanje lokalno

1. Instalirajte Python 3.
2. U terminalu, u ovom folderu, pokrenite:

   ```powershell
   py -m venv .venv
   .venv\Scripts\Activate.ps1
   py -m pip install -r requirements.txt
   py app.py
   ```

3. Otvorite http://127.0.0.1:5000.

## Objavljivanje

Repozitorij je pripremljen za Render. Povežite GitHub repozitorij na Renderu kao Web Service; `render.yaml` sadrži komande za instalaciju i pokretanje.
